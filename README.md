## Obiettivo
L’obiettivo di questo primo compito, da svolgere singolarmente, è creare una semplice app Flutter, personalizzarla e pubblicarne il codice su GitHub. L’app va poi eseguita sia su emulatore sia su uno smartphone fisico, per verificarne il corretto funzionamento.

## Istruzioni
1. **Configurazione dell’ambiente di sviluppo**:
   Configurate sul vostro computer l’ambiente di sviluppo necessario per creare ed eseguire applicazioni Flutter.
2. **Creazione e personalizzazione del progetto**:
   Create un nuovo progetto Flutter e, successivamente, apportate una modifica all’applicazione generata. In particolare, sostituite il nome o il titolo visualizzato nella schermata iniziale con il vostro nome e cognome. Avviate l’app su un emulatore per verificare che la modifica sia stata applicata correttamente.
3. **Pubblicazione del progetto su GitHub**:
   Create una repository GitHub pubblica e caricate al suo interno l’intero progetto Flutter. Verificate che la repository e i relativi file siano accessibili pubblicamente.
4. **Deploy ed esecuzione su dispositivo mobile**:
   Effettuate il deploy dell’applicazione sul vostro smartphone ed eseguitela direttamente sul dispositivo, verificandone il corretto funzionamento.
5. **Screenshot dell’applicazione**:
   Dopo aver avviato l’applicazione sullo smartphone, acquisite uno screenshot della schermata in esecuzione. Nello screenshot, il vostro nome e cognome devono essere chiaramente visibili.

## Materiale da consegnare
Per completare l’attività, caricate sulla piattaforma:
- il link alla repository GitHub pubblica contenente il progetto Flutter;
lo screenshot dell’applicazione in esecuzione sul vostro smartphone, nel quale siano chiaramente visibili il vostro nome e cognome.

## Verifiche prima della consegna
Prima di inviare il materiale, assicuratevi che:
- la repository GitHub sia pubblica e accessibile;
la repository contenga l’intero progetto Flutter;
- l’applicazione venga eseguita correttamente sullo smartphone;
il vostro nome e cognome siano chiaramente visibili nello screenshot.
